## Product truth

**“Curate” is not another tab.**  
It is an Opal **behavior**:

understand permitted context  
→ collapse cognitive work  
→ ask only what materially changes the answer  
→ hand the **same** reality into Graph / Journey  
→ learn from what actually happened.

Users may mean: “What should I do?” / “Pick for me.” / “Just decide.” / “Handle Saturday.” / “You know me. Choose.”
