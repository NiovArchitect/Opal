## Taxonomy

| Kind | Purpose | Cadence | Semantic? |
|------|---------|---------|-----------|
| **BRAND_AMBIENT_MOTION** | Opal feels gently alive at rest | Continuous, very slow, low amplitude | **NO** |
| **BEHAVIORAL_SIGNAL_MOTION** | Something meaningful changed | Event-driven, ≤2 soft pulses / &lt;1s orb breath | **YES** |
| **LIVE_COMMUNICATION_MOTION** | Something is actively occurring | Continues only while incoming/live | **YES** |
| **INTERACTION_MICRO_MOTION** | Press / sheet / selection feedback | Short, subtle | No (not state) |
| **CONTENT_MEDIA_MOTION** | Video/media | Media-owned | Separate |

## Behavioral timing (965:2 written law)

- Never persistent “AI working” glow
- Level 3: controlled pulse only while time-sensitive
- Level 4: repeating only while genuinely incoming/live
