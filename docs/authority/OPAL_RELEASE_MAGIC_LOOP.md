# Release Magic Loop

**Status:** CURRENT · launch product proof target  
**Date:** 2026-09-08

## The loop

```text
REAL USER
  → asks Opal naturally
  → personal context reduces steps
  → another person can be included (optional)
  → private contexts arbitrated safely
  → one answer / question / tradeoff
  → user accepts
  → action executes where supported (provider truth)
  → shared Graph updates
  → Journey
  → personal Material Time consequences
  → realtime change if reality changes (delta, not restart)
  → Memory
  → next interaction gets easier
```

## Solo wedge (must work with N=1)

> “Opal, what should I do tonight?”

Useful answer from permitted context immediately. No friends required.

## Interpersonal wedge

> “What about with Chanelle?”

No setup form. No rebuilding the query. Context deletes steps.

## Decision → commit → execute

```text
Juniper & Ivy · Saturday 7:30 PM
[ Reserve it ]
  → ActionIntent (not UI optimism)
  → Approval if required
  → ProviderReceipt
  → Graph provisional → confirmed
```

Law: **UI optimism may never outrun provider truth.**

## Live change

Reservation shifts / person drops / traffic changes → recompose **delta**, not restart.

## What this loop is not

- Muse connector catalog tour  
- Fake friends in a real account  
- Button labeled “reserved” without ProviderReceipt  
- R3/TURN/push as silent prerequisites for Solo value
