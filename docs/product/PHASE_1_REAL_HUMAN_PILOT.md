## Pilot law

**Let humans be human.**

Do **not**:

- script conversation  
- coach the second person into QA behavior  
- force availability forms  
- invent synthetic edge cases as the main workstream  

They **may**:

- be vague, late, busy  
- say “you pick” / “maybe”  
- ignore Opal  
- solve things manually  

That **is** the test.

---

## After every real alignment

Classify each meaningful remaining step:

| Type | Meaning |
|------|---------|
| `IRREDUCIBLE_HUMAN_AUTHORITY` | Yes/no, preference, consent, share, book/pay |
| `PRODUCT_DEFECT` | Opal had enough and still forced sludge |
| `MISSING_INTELLIGENCE` | Legitimately lacked learnable fact/understanding |
| `MISSING_PERMISSION` | Could help if authorized |
| `MISSING_INTEGRATION` | Provider/device boundary forced manual work |
| `EXECUTION_LIMITATION` | Aligned but handoff/contract couldn't finish |
| `USER_PREFERENCE` | Human chose to do it themselves |

**Primary questions**

1. What did humans still do that Opal could **reasonably and safely** have done?  
2. Was that work something a human **should** retain?
