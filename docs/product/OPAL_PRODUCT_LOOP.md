## Reinforcement loop

```
relationship
  → conversation
  → permitted signal
  → understanding
  → Graph
  → commitment / SharedPlan
  → Journey
  → lived experience
  → Memory
  → richer context
  → better next alignment
```

Short form used in founder language:

```
CONVERSATION → UNDERSTANDING → GRAPH → COMMITMENT → JOURNEY
  → REAL EXPERIENCE → MEMORY → BETTER NEXT ALIGNMENT
```

## Self-alignment is first-class

Opal must be useful when a human is alone.

Social participation multiplies value.
It is **not** required for the first useful experience.

## Engagement / network effect

Do **not** optimize merely for screen time.

Intended reinforcement:

```
signal → clarity → alignment → commitment → real experience
  → Memory/share → stronger relationship/context → easier next alignment
```

The product should encourage experiences worth repeating and sharing.

## Domain ownership

Every mutation has **one** domain owner.

No parallel Home / Chat / Graph / Journey / Opal engine.

## Fulfillment consequences (framing)

After alignment, potential fulfillment includes:

directions · transport · tickets · rentals · reservations · food · provider actions
