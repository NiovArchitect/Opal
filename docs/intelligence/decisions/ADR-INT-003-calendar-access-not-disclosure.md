# ADR-INT-003 — Calendar access ≠ disclosure

**Status:** ACCEPTED  
**Date:** 2026-08-13 (codified; privacy addendum pre-existing)

## Decision

Opal may know free/busy deeply for composition. Humans see minimum useful shared consequence. Raw calendar event details (titles like therapy, locations of private events) must not cross participant boundaries.

## Anchors

`AvailabilityComposition`, calendar privacy evidence, freebusy contracts.
