# ADR-INT-005 — One Shared Reality lineage

**Status:** ACCEPTED  
**Date:** 2026-08-13 (codified; V2 + domain pre-existing)

## Decision

A social plan is one evolving Shared Reality object/lineage. Temporal maturation and dimension updates must not spawn disconnected duplicate plans. Home / Chat / SR / Plans may differ in copy density but not core WHO/WHAT/WHEN/WHERE/next_gap truth.

## Anchors

SocialReality, ProductSignals, live Jordan same-lineage proof, four-surface consistency.
