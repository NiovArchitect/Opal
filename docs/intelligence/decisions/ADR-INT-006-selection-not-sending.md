# ADR-INT-006 — Selection ≠ sending

**Status:** ACCEPTED  
**Date:** 2026-08-13 (codified; place/extend private-first pre-existing)

## Decision

Private selection of place, time window, or Extend option does not send a message or settle shared reality for peers. Only explicit share/send (or equivalently intentional send of draft) crosses the boundary.

## Anchors

Place sheet, Extend panel, INT-AUTHOR-001, live side-effect audits.
