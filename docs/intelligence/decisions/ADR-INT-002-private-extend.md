# ADR-INT-002 — Private Extend

**Status:** ACCEPTED  
**Date:** 2026-08-13 (codified; behavior pre-existing)

## Decision

Extend from an active Shared Reality is private-first. Selecting options does not auto-message or mutate shared reality. Explicit share is separate. Extend is reversible/collapsible.

## Anchors

Extend panel in OpalApp, private-first tests, presentation laws.
