# Opal system moments (taxonomy)

Opal moments are **not** human messages or chatbot personae. They are conversation-scoped living state.

## Types

| Type | Examples | Meaning |
|------|----------|---------|
| Recognition | Becoming a plan | Meaningful movement recognized |
| Participation | Still open, Will know later | People deciding |
| Execution | Reservation requested | Approved action began |
| External state | Table held | Provider state affects users |
| Completion | Booked, Handled | Secured or done |
| Private | Keep private guidance | Owner-only |

## Visual distinction

- Separate surface from bubbles (`opal-moment` class)
- Label + mark, not a third chat participant
- Not under a person’s name as identity
- Color may reinforce type; text always present
- Quiet when no meaningful movement
