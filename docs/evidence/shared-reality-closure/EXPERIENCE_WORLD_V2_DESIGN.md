## Design system summary (strong recommendation)

### Art direction name: **Living Void**

Premium futurism ≠ neon glass everywhere.

| Layer | Behavior |
|-------|----------|
| **Calm** | Social space almost disappears; no glow; human content grounded |
| **Awakening** | Local spectral edge / filament when Opal notices something useful |
| **Transformation** | Brief emerald settle when reality locks — then recede |

### Palette (Figma variables: `Opal V2`)

| Token | Role |
|-------|------|
| `env/void` `#030508` | Base environment |
| `env/plane` `#070A10` | Soft human plane |
| `human/ink` `#F4F7FA` | Primary type |
| `human/secondary` `#8A96A8` | Secondary type |
| `opal/possibility` `#6EE7F5` | Awakening |
| `opal/private` `#8B7CFF` | Inward private |
| `opal/resolve` `#3DDF9A` | True resolution only |
| `media/warm` `#E8D5C4` | Media / place warmth |
| `safety/danger` `#E85A5A` | Safety |

### Type

Inter family: editorial bold for moments of life (“Tonight is happening.”), clean medium for social scan. 12–18 comprehension stress test: **instant**, minimal decoding.

### Brand mark

**No persistent logo halo.** Clean radial lens mark only. Motion reserved for intelligence acts.

### Opal material identity

**Not** gradient card + diamond.

**Is** spectral **filament / edge bar** — recognizable with logo removed; smaller than human messages; chronological.

### Depth / shadow

One ambient environmental shadow on living presence blocks. No generic 10×30 card shadow on everything. Shared Reality uses settled volumetric plate over place atmosphere.

### Media

Social Moments: edge-to-edge atmosphere first. Actionability (“Do this with your people”) only after interest. No Yelp stars.

## Screen map (V2)

### Home
Living social field · “Tonight is happening.” · **one** awaken choice · asymmetric presence blocks (not identical rows) · dock minimal.

### Chat
Organic message corners · Opal filament chronology · private inward violet field · no third-person AI bubble size.

### Shared Reality
Signature object · place atmosphere + glass settle · **no SET badge** · temporal only when useful (Tonight · leave-by).

### Curate
Dimensional rings · “I’ve got your evening.” · dinner · walk · dessert compressed · Looks good / Change vibe · becomes same Shared Reality.

### Extend
Grows from active SR · one continuation · quiet allowed.

### Social Moments
Media primary · place as text · intentional path only after interest · lineage to *own* circle.

### Plans
Field of usable realities (Tonight / Saturday / Tuesday) — not status backlog.

### Group / add person
Preserve still-true facts · recompute capacity · one human decision if needed.

### Temporal maturation
Far → Tomorrow → Tonight → Leave in 16 · never all at once.

### Motion language
RECOGNIZE → EMERGE → COMPOSE → CONVERGE → RESOLVE → SETTLE → RECEDE.
