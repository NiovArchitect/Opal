# Opal moment and execution copy

## Human vs Opal
| Role | Style | Example |
|------|-------|---------|
| Human | Calm bubble | We should get dinner Thursday. |
| Opal recognition | Spectral moment | Becoming a plan |
| Opal proposal | Spectral + option | Harbor Table could work · Thu 7:00 |
| Opal execution | Only if authorized | Booking Harbor Table · Requesting confirmation |
| Hold | Amber urgency | Table held |
| Done | Emerald | Booked / Handled |
| Fail | Ruby | Hold expiring |

## Walkthrough default until providers live
Use **proposal only**. Never claim booking as fact without real execution authority.

## Becoming a plan
Must not be: status chip, calendar tag, third participant, identity subtitle.
Must be: luminous cyan recognition, dark glass, mark + label + optional support.
