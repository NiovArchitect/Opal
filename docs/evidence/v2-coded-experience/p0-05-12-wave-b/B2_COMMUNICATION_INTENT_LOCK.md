# B2 — Direct / Group / Group Info Intent Lock

**Authority sync:** `b20082a` · **Universe:** `618:2`  
**Does not grant design freedom.** Preserves why communication surfaces matter.

## Shared product law

Conversation is an intelligence surface:

```
CONVERSATION → UNDERSTANDING → CONTEXT → ALIGNMENT → CONSEQUENCE
```

Do not collapse into generic AI chat, messaging SaaS, planner UI, task manager, or calendar workflow.

Click-friction: if WHO/WHEN/WHERE are already known in context, carry them — do not reopen setup.

Private intelligence must not become group-visible explanation without permission.
