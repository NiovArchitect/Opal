## C. SYSTEM DEFECT FIXED — VIEWPORT

**Root cause:** Home destinations used `position: fixed; inset: 0` relative to the **browser viewport**, escaping `.app { max-width: 480px }`. On anything wider than the phone column, Open Graph felt like a desktop web page / blowout.

**System fix:** shared mobile-column law for Graph / Memory / Comments / Discovery / Forward / Journey / Manage / CantMakeIt / Location / Profile / Story / NewChat:

- `left: 50%; transform: translateX(-50%); width: 100%; max-width: 480px; overflow-x: hidden`

Page must satisfy `scrollWidth <= viewport` unless a deliberate horizontal child scroller exists.
