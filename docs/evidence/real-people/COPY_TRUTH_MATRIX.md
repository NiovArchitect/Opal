# Copy truth matrix — Real People vertical

**Author:** Grok (lead)

| Kind | Meaning | Example |
|------|---------|---------|
| **HUMAN MESSAGE** | What a person said | We should study together this week. |
| **OPAL RECOGNITION** | Opal noticed a possible shared intention | Becoming a plan |
| **OPAL PROPOSAL** | Opal suggests an option (not executed) | This could work · Wednesday at 5:30 |
| **PARTICIPATION** | A user response | I’m in |
| **SHARED STATE** | Not everyone aligned yet | Still open |
| **SET** | Accepted participants agreed to this bounded plan | Set |

## Explicit non-claims for Set

- No provider contacted  
- No reservation made  
- No payment made  
- No calendar event unless separately authorized  
- No booking language  

## Private participation shared-safe only

- “One person needs another time.”  
- Never who / why / raw private response
