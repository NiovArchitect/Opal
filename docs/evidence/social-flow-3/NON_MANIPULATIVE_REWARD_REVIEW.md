## Allowed reward moments (socially meaningful)

| Moment | Example copy | Level |
|--------|--------------|-------|
| Agreement | “You both agreed on Saturday.” | L3 |
| Commitment done | “Reservation handled.” | L2 |
| Shared update | “Everyone has the updated plan.” | L3 |
| Open loop closed | “That question has been answered.” | L2 |
| Clarity | “You clarified what you meant.” | L2 |
| Empty needs-you | “Nothing else needs attention here.” | L1 |
| Settled plan | “The plan is settled.” | L2–L3 |
| Loop closed | “You closed the loop.” | L2 |

Reward comes from **real social progress**, not manufactured engagement.

## UI examples (SF-3)

- Pre-send: private insight card — Help answer / Send as written / Dismiss  
- Open loop: private — Reply now / Remind later / Not needed / Dismiss  
- Ambiguity: private — Ask clarification / Continue / Dismiss / Opal misunderstood  
- Repair: private — Help respond / Write myself / Dismiss  
- Decision summary: structured Confirmed / Still open / Handled  

No dashboard of badges. Reduced motion: text-only completion (system preference respected via SF-2 motion_preference when wired).

## Accessibility

- Non-color-only status  
- Screen-reader: “Opal suggestion” vs peer message  
- Touch targets ≥ 44pt on action labels (mobile conventions)

## Conclusion

SF-3 reward surface is **humane completion feedback** aligned with “Opal helped me understand / say what I meant,” not addiction design.
