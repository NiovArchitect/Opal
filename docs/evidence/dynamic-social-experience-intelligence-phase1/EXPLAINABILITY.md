# Explainability — Phase 1

## Allowed “See why” content

- Fits everyone’s current timing
- Quieter than the other options
- Convenient for the people involved
- Similar to places this group has enjoyed

## Forbidden

- User C cannot afford the alternatives
- User B has sensory sensitivity
- Exact participant locations
- Fit scores / friend scores
- Provider internals

Elixir sanitizes and validates shared payloads before projection.
