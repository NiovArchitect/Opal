# SF11 Information Architecture

Primary tabs only:

1. **Home** — calm orientation, Needs you (max 3), Coming up, Recent changes  
2. **Chats** — authorized conversations  
3. **Plans** — needs confirmation / today / upcoming / recent  
4. **You** — identity, devices, privacy, safety, family, accessibility  

Not primary: Signals, Reminders, Approvals, Memories, Safety, Family, Discovery, Traditions, Devices, AI.

Conversation remains the primary work surface when opened from lists or Needs you actions.
