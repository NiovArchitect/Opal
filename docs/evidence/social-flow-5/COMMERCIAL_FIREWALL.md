# Social Flow 5 — Commercial Firewall

## Boundaries

| Zone | Rule |
|------|------|
| Social truth | Plans, membership, constraints remain non-commercial |
| Intent | Explicit request / capability enablement / approved prompt only |
| Provider | Synthetic adapters; min disclosure; no raw messages |
| Ranking | Hard constraints first; sponsored bounded and labeled |
| Selection | Explicit group approval; no auto-book |
| Handoff | “You are leaving Opal.”; no payment; manual reservation mark |

## Prohibited data flow

- Raw conversation → provider/sponsor
- Private budget exact → group or provider
- Emotional/relationship state → ads
- Social Score → eligibility
- Payment → hard-constraint override

## Residual risk

Synthetic-provider and fixture-level URL checks. **Not** a full adversarial red-team or live ad-network audit.
