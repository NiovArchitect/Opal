# Isolated prototype — Social Moment → Shared Reality

**Not production.** Not linked from the live Opal shell.

## Open

Open `index.html` in a browser (file:// or any static server).

```bash
open docs/evidence/shared-reality-prototype/index.html
```

## What to feel

Chanelle’s dinner starts as **pure social content**. There is **no** permanent Book / Do-this chrome.

Only after a low-friction **intent** (tap place, save, or “I want to do this”) does Opal reveal **Do this with your people**.

That seeds an **independent** Shared Reality for *your* circle — not entry into Chanelle’s group.

**Keep it a picture** is a first-class success path.

## Law demonstrated

> Actionability can exist before it is visually present.  
> The moment should not advertise actionability before the viewer expresses interest.

## Success criteria (all must pass)

1. Social-first (Chanelle’s life, not monetization)  
2. Actionable without commerce smell  
3. Independent experience (not her original circle)  
4. Opal-native (alignment, not shopping)  
5. Quiet (action doesn’t compete with photo/caption)  
6. Optional (leave with only ❤️)  
7. Cold-start value  
8. Network value when another person joins  
9. No authority collapse (see ≠ participate ≠ inspire ≠ attribute)  
10. No marketplace drift  

## Cold review questions

1. Instagram + book button, or friend’s life → my plan?  
2. Does actionality ruin authenticity?  
3. Can you simply ❤️ and leave — and still feel complete?  
4. Did “Do this” appear only after you showed interest?
