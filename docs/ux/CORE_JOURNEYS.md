# Core Journeys

**Status:** Phase 0

---

## Journey 0 — First value (MVP spine)

Two consenting adults, synthetic or real phones (dev).

1. A verifies phone (or dev login).  
2. B verifies phone.  
3. A invites B (link or search).  
4. A sends text; B receives realtime.  
5. Airplane mode: A queues message; reconnect delivers once.  
6. A sends voice note; B plays; transcript available with consent.  
7. B requests translation; original remains visible.  
8. A writes “I’ll call you tonight”; Opal proposes commitment; A confirms.  
9. Reminder surfaces later.  
10. B is upset; uses Help me say this; picks a draft; sends manually.  
11. B revokes shared AI (if any); private notes stay private.  
12. A deletes relationship context; evidence shows expected removals.

Block → no messages, no presence leak, no AI cross-context.
