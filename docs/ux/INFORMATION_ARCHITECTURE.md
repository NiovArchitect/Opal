# Information Architecture

**Status:** Phase 0 candidates — **not frozen**

---

## Navigation candidates

| Tab / root | Purpose | MVP? |
|------------|---------|------|
| **Conversations** | Chat list + threads | Yes |
| **People** | Contacts, invites, circles (later) | Thin MVP |
| **Flow** | Plans, commitments, soft calendar | Commitments only MVP; full Flow later |
| **Opal** | Personal assist, reflections, settings entry | Careful — not chatbot home |

Alternative to evaluate: 3-tab (Chats / Flow / You) with Opal actions contextual inside chats.

---

## Conversation surfaces

- Message stream  
- Composer (text, voice)  
- Contextual chips: Translate · Help me say this · What’s unresolved  
- Private reflection sheet  
- Shared plan / commitment cards (compact)  
- Conversation settings: notifications, AI permissions, block  

---

## Settings hierarchy (progressive)

1. During use: contextual permission prompts  
2. Conversation-level AI controls  
3. Account-level privacy & AI features  
4. Advanced / legal  

Avoid settings wall before first value.

---

## Anti-IA

- Agent topology screen  
- Global sentiment dashboard  
- Relationship scoreboard  
- Nested AI “apps” marketplace in MVP
