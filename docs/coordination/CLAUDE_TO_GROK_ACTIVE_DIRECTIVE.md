### Directive body

**Standing product direction (not a one-shot task):** Opal Alignment Loop — full behavioral operating system.

Internalize above almost everything else:

> **The AI should do more work; the user should experience less software.**

Deeper meaning:

> Opal should continuously maintain a private, permission-aware model of reality around the relationship or group; detect when uncertainty has meaningfully collapsed; then surface only the smallest decision that humans still uniquely need to make.

And:

> Opal should do the coordination work before asking humans to do coordination work.

Canonical loop (with quiet → remember):

**know what happened → know what is still possible → notice what just became easy → compress the world → humans make one meaningful choice → execute → become quiet → remember the new reality.**

Full text is appended at the bottom of this file under **STANDING — OPAL ALIGNMENT LOOP**.

- Interpret the loop as a linear wizard
- Add cards/toggles/menus/wizards/fields/dashboards for every new capability

- Expose the full comparison matrix to users
- Claim execution (booked/paid/shared) without provider confirmation
- Keep narrating after execution when quiet is correct
- Reopen protected recovery/freshness/trust infrastructure without a failing test

==================================================

ACTIVE TRUTH

HISTORICAL TRUTH

EXPIRED TRUTH

SUPERSEDED TRUTH

PRIVATE TRUTH

SHARED TRUTH

DERIVED TRUTH

PROVIDER TRUTH

INFERRED TRUTH

==================================================
