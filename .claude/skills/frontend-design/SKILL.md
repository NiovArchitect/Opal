# Frontend Design (Opal-local)

Approach this as design lead for a product that must not look like every other AI app. Founder wants **peak brand**, not safe SaaS.

## Opal overrides (always win)

- Full Technicolor walkthrough vs Controlled member product
- Human calm / Opal luminous spectral moments
- OPAL wordmark authority over decorative orbs
- Age-12 copy; no architecture jargon in UI
- State honesty: human vs proposal vs action vs confirmed
- Dopamine = social progress, not gamification

## Design principles

- Hero is a thesis — first screen must answer “what is this?” with beauty + category demo
- Typography carries personality; pair display/body deliberately for Opal (not Inter-by-default unless product already established)
- Structure is information — don’t number steps just because onboarding templates do
- Motion is deliberate — orchestrate with `opal-motion-director`; less is more when effects read as AI-generated
- Match complexity to vision; Full can be cinematic; Controlled stays sustainable

## Anti-defaults (revise if you land here without product reason)

1. Warm cream + high-contrast serif + terracotta  
2. Near-black + single acid green/vermilion  
3. Broadsheet hairlines, zero radius, dense columns  

Opal already has a Technicolor system — **extend it**, don’t replace with a template look.

## Process

1. Read `docs/coordination/FOUNDER_NUANCE_PACK.md`  
2. Ground in `FirstRunExperience.tsx` + Technicolor tokens  
3. Plan: palette, type, layout, **one signature**  
4. Critique against anti-defaults  
5. Spec for Grok (concrete CSS/React)  
6. Reduced-motion + 390 width + contrast pass  

## Restraint

Spend boldness in one place (signature). Keep surroundings quiet. Before shipping a proposal: remove one accessory.
