# Design masters — the drawn brand (source of truth)

The founder's live-drawn brand masters: the opal orb (gyroscope
rings, points of light) and the wordmark (gem-cut O). These files are
the SOURCE OF TRUTH for the brand. Quality-survival law (founder,
2026-10-18 06:09 PDT; communication-model.md §8.1):

- DERIVE, DON'T REDRAW. Assets are produced by REDUCTION from these
  masters (luminosity keying, programmatic color sampling, vector
  reductions of the master geometry) — never reinterpreted by eye.
- Hero asset = the master itself, near-black keyed to transparent,
  for large dark-field placements (splash/opening/Center presence).
- Light mode gets a VARIANT (the stone in its own dark medallion —
  jewel-in-case), never an inversion of the dark art.
- Vector reductions (gem O, ring, gradient tokens) serve small sizes
  and chrome.
- Palette + gradient stops are SAMPLED PROGRAMMATICALLY from these
  masters and stored as design tokens; code never approximates the
  colors from memory.
